# 시드업자산

클로드의 매매 조언 + 가계부(지출)를 합친, 휴대폰 홈 화면에 설치해 쓰는 앱. 소원저장소와는 별도 앱이다.

- 숫자는 **맥북 정리 스크립트**(`신혼테크/도구/시드업자산_정리.py`)가 카드 명세서·승인 문자·잔고 캡처·네이버 시세를 모아 PIN으로 **AES-GCM 암호화**해 비공개 저장소 `sein9507-max/newlywed_tech` 의 `시드업자산/data.enc.json` 에 올린다.
- 앱은 그 파일을 받아 **이 휴대폰 안에서만** PIN으로 푼다. 서버 없음, 로그인 없음. 외부 요청은 `api.github.com` 하나뿐(CSP).
- GitHub 열쇠(fine-grained token)와 PIN은 **휴대폰 브라우저 localStorage 에만** 둔다.
- 매매일지는 `시드업자산/매매일지/YYYY-MM.jsonl` 에 한 줄씩 덧붙인다(저장소가 비공개라 평문. 금액 자료와 달리 클로드 루틴이 읽고 복기 피드백을 줄 수 있게).

## 탭 5개 (1.2.0 — 첫 화면은 '조언', 기본 테마 C 블랙 크롬 라임)
> **본인 전용 앱이다.** 조언 탭은 사용자 한 사람의 보유 종목에 대한 종목별 조언을 담는다. 회원·공개용으로 배포하거나 같은 내용을 남에게 팔면 유사투자자문·투자자문업 문제가 생기므로 **회원 배포 금지**.

1. **조언** (앱을 열면 언제나 여기) — 위에서부터
   - **오늘 컨디션 원터치**: 😫😕😐🙂😆 한 번 누르면 오늘 날짜에 기록(다시 누르면 변경). 바로 아래 접히는 **한 달 달력**에 그날 이모지. 저장소 `시드업자산/컨디션/YYYY-MM.json`(`{"days": {"YYYY-MM-DD": {"v": 1~5, "at": …}}}`), 오프라인이면 매매일지와 같은 대기열. 1~2단계인 날은 브리핑·조언 카드에 "오늘은 관망·소액만" 한 줄.
   - **장전 브리핑 2장**: 🇰🇷 코스피 장전(평일 07:00 이후 첫 동기화 — 지난밤 미국장·주말 반영) / 🇺🇸 나스닥 장전(평일 22:00 이후 첫 동기화 — 오늘 국장·미국 프리장·선물·오늘 밤 지표 반영). 각 1~3줄 + 생성 시각, 최신이 위. 새 브리핑을 아직 안 봤으면 탭에 배지.
   - **클로드의 매매 조언**: 보유(`보유.json`)·관심(`관심.json`) 종목마다 국면 / 행동(관망·분할매수 검토·비중 축소 검토·손절선 점검) / 근거 2줄 / 무효화 / 레버리지 위험 / **차트 그림**(일봉 120일 캔들 + 5·20·60일선 + 거래량 + 클로드가 짚은 지지·저항·무효화 선, 저장소 `시드업자산/차트/<코드>.png`, 금액 정보 없음) + 트레이딩뷰로 여는 링크. 첫 종목 차트만 바로 받고 나머지는 눌러야 받는다(휴대폰에 해시별로 담아둠).
   - **직접 계획**(접힘) — 옛 '체크' 탭: 시황 발행본 → 시장 국면·즉시 중단 신호 → 플레이북 순서 거래 계획 → 라임 "수량 N주".
2. **오늘** — 한 화면에: 총자산 큰 숫자 + 어제 대비 → **오늘 할 일 3개**(장전 조언 보기/기록/복기 순서 자동) → 오늘/이번 달 지출·저축률·비상금 2×2 → 최근 지출 3건. (월 수입은 들쭉날쭉이라 설정 ③ 칸은 비워 둠)
3. **지출** — 이번 달 총액·지난달 같은 날 대비·남은 예산 → 카테고리 막대(누르면 그 분류만) → 날짜 묶음 목록. 결제 겹침 경고 한 줄, TOP5·고정비는 접힘.
4. **투자** — 평가금액·손익 → 비중 막대 + 리밸런싱 알림 한 줄 → 계좌별 보유(접기) → 매매일지 최근 3건.
5. **복기** — 이번 주 점수(전주 대비) → 반복 실수 → 다음 주 교정 행동 한 줄 → 지난 주 비교표. 일요일엔 배지.

### 조언은 어떻게 만들어지나 (맥북)
`신혼테크/도구/시드업자산_조언.py` — `블로그_동기화.sh`(5분마다)가 정리 스크립트 바로 앞에서 부른다. 평일 07시·22시 슬롯을 하루 한 번씩만 만든다(주말은 장이 없어 마지막 것 유지).
1. 네이버 무키 일봉(`api.stock.naver.com/chart/…/day`) ~300일 → 이평 위치·배열, 거래량 20일 평균 대비, 52주 고저, ATR14, RSI14, 스윙 지지·저항 계산.
2. 시황 데이터 파일(`주식시황정리/데이터/<날짜>.txt`)·실시간 지수·발행본·유튜브 자막·컨디션·매매일지·학습 문서 요점(돈깡 플레이북·레버리지 일간 정산 경고·약한 고리)을 넣어 맥북 `claude -p`(구독, 도구 없음) → JSON. 자료에 없는 숫자가 브리핑에 있으면 한 번 다시 묻는다. 한도면 다시 시도 시각을 적고 쉰다.
3. 클로드가 고른 가격선으로 차트 PNG를 그려 저장소에 올리고, `~/.newlywedtech/시드업자산/조언/advice.json` → 정리 스크립트가 `data.json` 의 `advice` 로 넣어 PIN 암호화 업로드.
- 수동: `python3 도구/시드업자산_조언.py --슬롯 us` · 가짜 응답 시험 `--시험`(결과는 `조언/시험/`만) · `--미리보기` · `--상태`.
- 트레이딩뷰는 로그인·약관 때문에 자동 캡처하지 않는다. 링크만 단다.
- 어느 탭에서든 오른쪽 아래 **+ 버튼** → 매매일지 / 지출 메모. 저장 뒤 4초 동안 "되돌리기" 가능(그동안은 올리지 않음).
- 지출 메모는 `시드업자산/지출메모/YYYY-MM.jsonl` 에 한 줄씩 쌓인다. 같은 날 같은 금액의 카드 거래가 들어오면 앱이 자동으로 빼고 센다(정리 스크립트는 아직 메모를 읽지 않음).

## 쓰는 법
1. 맥북: `python3 도구/시드업자산_정리.py --핀` 으로 PIN 확인 (처음 실행 때 6자리를 만든다).
2. 휴대폰 Safari 로 앱 주소를 열고 → 공유 → **홈 화면에 추가**.
3. 홈 화면 앱을 열어 설정 ⚙ → ① GitHub 열쇠(안내대로 발급, Contents **Read and write**) → ② PIN 입력.
4. 자료 넣는 길: 앱 "넣는 법 보기" 또는 저장소 `시드업자산/단축어_만드는법.md`.

## 배포 (아직 안 함 — 사용자가 "발행"이라 하면)
1. GitHub 에 **공개** 저장소 하나 새로 만든다(예: `sein9507-max/sidup-asset-app`). 앱 파일엔 비밀이 없다(열쇠·PIN·숫자는 저장소에 없음).
2. 이 폴더에서:
   ```
   git init && git add -A && git commit -m "시드업자산 1.0.0"
   git remote add origin https://github.com/sein9507-max/sidup-asset-app.git
   git push -u origin main
   ```
   (`_design/` 은 .gitignore 로 빠진다.)
3. 저장소 Settings → Pages → Source: **Deploy from a branch**, Branch: `main` / `(root)` → 저장. 1~2분 뒤 `https://sein9507-max.github.io/sidup-asset-app/`.
4. 아이폰 Safari 로 열어 홈 화면에 추가. (소원저장소와 주소가 다르므로 저장 공간도 따로다.)
5. 고칠 때마다: 파일 수정 → `sw.js` 의 `CACHE` 버전 올리기 → 커밋·푸시. 휴대폰은 다음에 열 때 새 버전을 받는다.
