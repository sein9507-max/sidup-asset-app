            설정

            ① 저장소 열쇠

            내 비공개 저장소()의 암호화 자료를 읽고 매매일지를 쌓으려면 GitHub 전용 열쇠가 필요해요. 열쇠는 이 휴대폰 안에만 저장돼요.

            열쇠 발급 방법 보기
            1. 아래 버튼으로 GitHub 열쇠 발급 페이지를 열어요(로그인 필요).
            2. Token name에 시드업자산, Expiration은 1년 정도.
            3. Repository access → Only select repositories → newlywed_tech만 고르기.
            4. Permissions → Repository permissions → Contents를 Read and write로. (읽기만 하면 매매일지를 못 써요)
            5. Generate token → 나온 github_pat_…을 복사해서 위 칸에 붙여넣기.
            열쇠 발급 페이지 열기 ↗

            ⑦ 지우기

            자료가 들어오는 길

            1. 카드 명세서 → iCloud 폴더

            아이폰 파일 앱 → iCloud Drive → 💰 시드업자산 (서류 넣는 곳)

            1. 삼성카드 앱/홈페이지의 이용내역 인쇄(PDF) 또는 메일로 온 엑셀을 연다.
            2. 공유 → 파일에 저장 → 위 폴더.
            3. 맥북이 5분 안에 읽고 처리완료/로 옮겨요. 거래는 승인번호로 겹치지 않게 합쳐요.

            2. 잔고·체결 캡처 → 사진첩

            1. 평일 장 끝나고 엠스탁 국내 잔고 · 해외 잔고 · 연금 · 예수금 화면을 캡처.
            2. 청약통장·교원라이프·온누리는 바뀔 때만.
            3. 사진첩에 그대로 두면 돼요(또는 위 iCloud 폴더에 넣어도 됨). 클로드가 읽어서 보유.json을 고치고, 현재가는 네이버 시세로 새로 받아요.

            자동 OCR은 아직 다음 단계라, 지금은 클로드에게 "캡처 반영해줘" 한 마디면 돼요.

            3. 삼성카드 승인 문자 → 단축어

            삼성카드 바로알림 문자(월 300원)를 신청하면 승인마다 문자가 와요. 단축어 자동화가 그 문자를 iCloud 폴더의 문자/에 한 줄씩 붙여 넣고, 맥북이 바로 지출에 넣어요.

            1. 단축어 앱 → 자동화 → + → 메시지.
            2. 조건: 메시지에 포함 = 삼성카드, 즉시 실행 켜기(확인 없이).
            3. 동작: 「현재 날짜」(yyyy-MM-dd HH:mm) → 「텍스트」로 [날짜] + 탭 + [메시지] → 「텍스트 파일에 추가」(iCloud Drive/💰 시드업자산 (서류 넣는 곳)/문자/승인.txt).

            자세한 화면별 순서는 저장소 시드업자산/단축어_만드는법.md에 있어요. 교통·자동이체처럼 문자가 안 오는 건 월말 명세서로 메워요.
